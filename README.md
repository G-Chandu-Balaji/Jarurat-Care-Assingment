# Cancer Awareness Website 🩷

A modern, responsive React application designed to raise cancer awareness, provide emotional support, and build community connections for those affected by cancer. Built for the Jarurat Care assignment with cutting-edge web technologies.

## 🌟 Features

- **Emotional Support**: Connect with trained counselors and support groups
- **Education & Resources**: Comprehensive information about prevention, detection, and treatment
- **Community Building**: Join a caring community of survivors, caregivers, and advocates
- **Research Updates**: Stay informed about the latest breakthroughs in cancer research
- **Interactive Contact Form**: Easy way to reach out for support
- **Responsive Design**: Optimized for all devices and screen sizes
- **Smooth Animations**: Enhanced user experience with Framer Motion

## 🚀 Tech Stack

- **Frontend**: React 19, React DOM 19
- **Build Tool**: Vite 7
- **Styling**: TailwindCSS 4
- **Animations**: Framer Motion 12
- **Icons & UI**: Custom glass-morphism design system
- **Development**: ESLint, Hot Module Replacement (HMR)

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm or yarn

## 🛠️ Installation & Setup

1. **Clone the repository**:

   ```bash
   git clone https://github.com/G-Chandu-Balaji/Jarurat-Care-Assingment.git
   cd jarurat-care-assignment
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the development server**:

   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:5173`

## 📜 Available Scripts

- **`npm run dev`** - Starts the development server with hot reload
- **`npm run build`** - Builds the project for production
- **`npm run lint`** - Runs ESLint for code quality checks
- **`npm run preview`** - Previews the production build locally
